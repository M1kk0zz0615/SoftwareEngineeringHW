自动生成小学四则运算题目的命令行程序：用 `-n`、`-r` 出题并算出答案，
用 `-e`、`-a` 判定作答对错。C# 实现，8 个源文件约 2200 行，内置 66 项自检。

## 一、怎么用

仓库里已经带了编译好的 **Myapp.exe**，可以直接运行；要重新编译见第三节。

```bat
:: 生成 10 道数值范围 10 以内的题目，写出 Exercises.txt 与 Answers.txt
Myapp.exe -n 10 -r 10

:: 判定答案对错，写出 Grade.txt
Myapp.exe -e Exercises.txt -a Answers.txt

:: 仓库自带一组手工示例，可以直接试判题
Myapp.exe -e samples\Exercises.txt -a samples\Answers_wrong.txt

:: 运行内置自检（66 项断言，全通过返回退出码 0）
Myapp.exe --selftest
```

`-n 6 -r 10` 的一次真实输出（左为 Exercises.txt，右为 Answers.txt）：

```
Exercises.txt                 Answers.txt
7 + 3 =                       10
8 + 5/9 − 2/3 =               7'8/9
8 ÷ (9 − 0 + 2) =             8/11
7 × 8 ÷ (8 × 8) =             7/8
1 + 7 − 2 + 5 =               11
2/5 × (1/3 − 0) =             2/15
```

判题结果 `Grade.txt` 的格式：

```
Correct: 5 (1, 3, 5, 7, 9)
Wrong: 5 (2, 4, 6, 8, 10)
```

## 六、关键设计

### 1. 分数用 `BigInteger` 精确表示（`Fraction.cs`）

构造时立即约分、分母恒为正，因此没有浮点误差，"相等"退化成分子分母的直接比较；
比较大小用交叉相乘，不会因为精度问题误判。

输出格式按作业要求：整数直接输出，真分数输出 `3/5`，假分数输出成带分数 `2'3/8`。

### 2. 表达式用二叉树表示（`Expression.cs`）

作业文法 `e = n | e1 + e2 | e1 − e2 | e1 × e2 | e1 ÷ e2 | (e)` 中的括号不占节点，
渲染时按优先级自动补全，所以既不丢括号也不输出多余括号：

| 表达式 | 输出 |
| --- | --- |
| `(1+2)×3` | `(1 + 2) × 3` |
| `1×(2+3)` | `1 × (2 + 3)` |
| `1÷(2÷3)` | `1 ÷ (2 ÷ 3)`（除法不满足结合律，右侧必须保留括号） |
| `(1÷2)÷3` | `1 ÷ 2 ÷ 3`（左结合，左侧不必加括号） |

### 3. 查重：规范形式（需求 7）

每个二元节点整体加一对括号，**加法与乘法的左右子树按字典序排序**后拼接，得到规范串：

- `23 + 45` 与 `45 + 23` → 都是 `(23+45)`，判为重复
- `6 × 8` 与 `8 × 6` → 都是 `(6×8)`，判为重复
- `3 + (2 + 1)` 与 `1 + 2 + 3`（即 `(1+2)+3`）→ 都是 `((1+2)+3)`，判为重复
- `1 + 2 + 3` 与 `3 + 2 + 1`（即 `(3+2)+1`）→ 分别是 `((1+2)+3)` 与 `((2+3)+1)`，**不重复**

与作业需求 7 给出的正反例完全一致。

### 4. 生成时如何保证约束（需求 4、5）

- **减法**：若左值小于右值就交换左右子树，交换后仍是合法题目，且结果非负；
- **除法**：只有 `0 < 左值 < 右值` 时结果才是真分数，不满足就交换左右；若左右相等或含 0
  则改用加、减、乘之一，避免整道题作废、白费一次尝试。

### 5. 题目质量

- 约 30% 的概率生成分数操作数（分子分母都在 `-r` 范围内）；
- 数值 0 与 1 的出现概率刻意压低，且一道题里 0/1 操作数超过 2 个就重新出题，
  避免 `1 × 1 × 1 × 2` 这类没有意义的题目。

## 七、性能

`-n 10000 -r 10` 实测（生成 + 写文件 + 判题的耗时由程序自行打印）：

| 阶段 | 耗时 |

| 生成 10000 道互不重复的题目并写出两个文件 | **68.9 ms** |

## 十、几点实现取舍

1. **带分数**：作业把 `1'1/2` 也列在真分数的例子里，因此题目中的分数允许是假分数，
   显示时统一化成带分数（如 `3/2` 显示为 `1'1/2`）；但需求 5 说的"除法的结果应是真分数"
   按严格意义实现，即结果必须满足 `0 < 结果 < 1`。
2. **文件编码**：写出的文件统一使用带 BOM 的 UTF-8，记事本打开不乱码；
   判题时先按 UTF-8 解码，若不是合法 UTF-8 再退回 GBK，因此别人手工用 ANSI 保存的题目文件也能判。
3. **`-r 1`**：此时所有数值只能是 0，能出的不重复题目极少，程序不会崩溃，
   而是生成尽可能多的题目并明确提示"可出的题目已用尽，请把 -r 调大"。
4. **判题只比较数值**：正确答案是 `3/2` 时，写成 `6/4` 或 `1'1/2` 都判为正确。
